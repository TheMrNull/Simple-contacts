# A simple contact app to test some personal and basic knowledge for my c++ exam.

This is a simple contact app made from scratch and written in c++ that lets you:  
1)Add  
2)Remove  
3)Search  
4)Export the contact list  
  
  
A compiled version named `contacts` is already provided.  
Manual compilation can be done with `g++ main.cpp funcs.cpp` or any preferred compiler.
